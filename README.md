# Traffic Law Hybrid RAG Chatbot

## 1. Giới thiệu
Dự án xây dựng một chatbot hỏi–đáp **Luật Giao thông Việt Nam** dựa trên mô hình **Hybrid Retrieval-Augmented Generation (Hybrid RAG)**.

Hệ thống cho phép người dùng đặt câu hỏi tự nhiên và nhận câu trả lời có căn cứ từ văn bản luật, kết hợp nhiều cơ chế truy xuấ.

## 2. Mục tiêu dự án
- Xử lý và chuẩn hoá văn bản Luật Giao thông Việt Nam từ PDF  
- Xây dựng hệ thống truy xuất lai tri-hybrid retrieval  
- Phát triển chatbot trả lời câu hỏi chính xác, có trích dẫn điều luật  
- Thực hành quy trình làm việc nhóm và quản lý mã nguồn với Git/GitHub
